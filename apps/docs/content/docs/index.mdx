title: upload-stuff
description: A typed, presigned-S3 file-upload library for React and Next.js.
---

upload-stuff is a file-upload library built on presigned S3 uploads, a typed
[Hono](https://hono.dev) RPC layer, and React hooks. Define a typed file router
on the server, wire it into your Next.js App Router, and call `useUploadStuff`
from the client.

Every code sample on this site is type-checked against the current packages, so
nothing you copy here is stale:

```ts twoslash
import { z } from "zod";
import { createUploadStuffRouter } from "@upload-stuff/server";

// Hover any identifier — the types come straight from the published packages.
const schema = z.object({ folderId: z.string() });
//    ^?
```
