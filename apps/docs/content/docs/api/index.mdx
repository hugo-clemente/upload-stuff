### Builder methods

`createUploadStuffRouter()` returns a function that takes a `RouteConfig` and
returns a chainable builder. The chain is generic (each method narrows the route
type), so it is documented by hand:

| Method | Description |
| --- | --- |
| `.input(schema)` | Attach a [Standard Schema](https://standardschema.dev)-compatible input parser (e.g. Zod). |
| `.middleware(fn)` | Run server-side logic; the returned data is forwarded to `onUploadComplete`. |
| `.fields(fn)` | Resolve values for the instance's declared custom `fields`; required when a field is declared `required`. |
| `.onUploadComplete(fn)` | Called after the S3 upload is verified; the return value is sent back to the client. |
| `.build()` | Finalize and return the `FileRoute`. |

### Hook options

The second argument to `useUploadStuff`. All fields are optional.

| Option | Type | Description |
| --- | --- | --- |
| `headers` | `HeadersInit` | Extra headers sent with the init/complete requests. |
| `onBeforeUploadBegin` | `(params) => File[] \| Promise<File[]>` | Transform the files before upload (e.g. client-side compression). |
| `onUploadBegin` | `(params: { file: string }) => void` | Fires when a file starts uploading. |
| `onUploadProgress` | `(percent: number) => void` | Global upload progress. |
| `onClientUploadComplete` | `(res) => void` | Runs after the server's `onUploadComplete`; receives the typed server data. |
| `onUploadError` | `(error: Error) => void` | Fires when an upload fails. |
| `onUploadAborted` | `() => void` | Fires when an upload is aborted. |
| `uploadProgressGranularity` | `"all" \| "fine" \| "coarse"` | How granular progress events are. |
